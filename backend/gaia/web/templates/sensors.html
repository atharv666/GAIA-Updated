How sensor data becomes knowledge

Every closed window is aggregated deterministically (count, min, max, mean, std) and written as a text chunk; each day also gets a rollup with time-of-day profiles and threshold events. Chat questions about numbers are answered from exact SQL statistics, never from the language model’s memory. Soil moisture is only logged while the rover is parked with the probe arm lowered. MQ gas values are uncalibrated relative indices.
